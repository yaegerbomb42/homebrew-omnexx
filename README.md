# homebrew-omnexx

Homebrew tap for [omnexx](https://github.com/yaegerbomb42/omnexx): a coding agent that runs
for days. Set a goal, walk away, come back to commits.

```sh
brew install yaegerbomb42/omnexx/omnexx
omnexx --ollama      # or: omnexx doctor
```

The formula installs the npm package with Homebrew's Node, plus ripgrep for fast search. It is
generated by `scripts/brew-formula.sh <version>` in the main repo after each npm release.
